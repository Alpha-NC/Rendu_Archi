# Rendering Intelligence Framework — V1.4 Review

Le RIF est un cadre indépendant des moteurs d'IA pour préparer, produire, contrôler et corriger des rendus architecturaux en donnant la priorité à la fidélité du projet.

## Contenu

- `Framework/` : les 15 modules métier canoniques et les 5 documents de gouvernance ;
- `Documentation/` : PRD RIF-App, synthèse des retours terrain et manifeste ;
- `Implementations/RIF-App/` : profil propre à Évariste, séparé du noyau universel ;
- `Tests/` : plan de validation avant passage Stable ;
- `Exemples/` : exemple de structure d'état projet ;
- `Backlog/` : éléments utiles mais hors du noyau V1.4.
